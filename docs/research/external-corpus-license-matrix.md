# External corpus license matrix (2026-09-15)

Status: research note for the external-corpus stress-test (see [external-corpus-stress-test.md](external-corpus-stress-test.md)). Verdicts use exactly one of: `CLEAR_COMMERCIAL`, `CLEAR_NONCOMMERCIAL_ONLY`, `RESEARCH_ONLY_OR_RESTRICTED`, `UNKNOWN`, `CONFLICTING`, `NOT_APPLICABLE`. Public availability is never treated as commercial permission. Per Phase A instructions, Kaggle/HF mirrors are not trusted as definitive when an original source exists; conflicts are recorded, not silently resolved in the more permissive direction.

None of the datasets below have been ingested, downloaded in bulk, or merged into any pilot artifact. This matrix documents license status only.

## Reading note on "Confidence" and "VERIFIED / INFERENCE / OPEN"

Per the evidence-discipline rule for this task: rows marked VERIFIED above were read directly from a primary artifact (dataset card YAML, repository LICENSE file, paper text) during this research pass. The AnnoMI CC0 claim is explicitly flagged as **OPEN** pending a direct read of the MDPI Data Availability Statement (blocked by an HTTP 403 in this session) and must not be treated as settled before any future ingestion decision. The ProsocialDialog component-source caveat is similarly **OPEN**, not resolved, because it was judged out of scope given the DROP recommendation for that dataset.
