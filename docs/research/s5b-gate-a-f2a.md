# Gate A-F2a: агрегатная трёхуровневая модель, усиленный контраст

Локальный gate, без Actions. Код — `execution/s5b_execution/af2a.py`,
к планировщику НЕ подключён (проверяется импортом). `UNDIVIDED_SHARE`
остаётся `None`. Коэффициенты малого просмотра никуда не переносятся.
Instrumentation — NO-GO; Gate B — NO-GO; 64000 — NO-GO.

A-F1 остаётся INCONCLUSIVE по СВОЕМУ порогу 2%. Здесь новый дизайн с
новым запасом решения: сигнал строится в 3–5 раз крупнее, а не
выслеживается под шумом.

## Предрегистрация

Этот раздел и пороги в коде закоммичены ДО замера.

### Модель и роли

```
C(P) = g(P)·A + n(P)·ΣB + K        n — в скольких группах КАЖДЫЙ δ
```

Все разбиения держат `n` одинаковым для всех δ, поэтому нужны только A и
ΣB. K одинакова у всех: каждый ключ ровно один раз.

```
      g  n  пар(группа,δ)  пар(группа,δ,days)   роль
P1    1  1        4              12             подгонка
P4    4  1        4              12             подгонка   A  = (P4 − P1)/3
F6    6  6       24              72             подгонка   ΣB = (F6 − P1 − 5A)/5
Q6    6  2        8              12             ОТЛОЖЕН    P1 + 5A + ΣB
H4    4  2        8              16             ОТЛОЖЕН    P1 + 3A + ΣB
C6    6  6       24              72             ОТЛОЖЕН    = F6
```

F6 — factorial `(2h + x + 2d + t) mod 6`, балансирует все координаты.
C6 — cells, изолирует клетку (horizon, maximise). Q6 — смежные
`key_slices(6)`. H4 — кольцо: каждый блок 9+9, половины в две соседние из
четырёх групп.

В выражении через измеренные суммы:

```
Q6_pred = −8/15·P1 + 4/3·P4 + 1/5·F6
H4_pred =  2/15·P1 + 2/3·P4 + 1/5·F6
```

Если у F6 есть скрытый уровень (группа, δ, days), он уйдёт в ΣB, а Q6 —
единственный отложенный, у кого блоки days целы (12 пар, как у
неделёного), — его и поймает.

### Порядок

Подбор просмотра: удвоение от 2, пока неделёный не стоит 4 с ЦП; пересчёт
на 60 с; заморозка.

Шаг 0: три СВЕЖИХ P1 на замороженном просмотре; пробы в них не входят.

Основной замер: три раунда, в каждом все шесть разбиений. Позиции
(`P1 P4 Q6 H4 F6 C6`) по раундам `0 1 2 3 4 5`, `2 3 4 5 0 1`,
`5 3 1 0 4 2`; суммы позиций 7, 7, 7, 8, 8, 8. Таймер — ЦП; стена
пишется рядом.

### Kill-gates, по старшинству

```
любое изменение научного результата          KILL_SPLIT_CHANGED_SCIENCE
шаг 0 неполон или среднее трёх P1 вне 45–75 с INCOMPLETE
шаг 0: max/min трёх P1 > 1.05                 INCONCLUSIVE_NOISE — STOP
основной замер неполон или бюджет 35 мин      INCOMPLETE
max/min трёх повторов суммы любого > 1.05     INCONCLUSIVE_NOISE
A < 0 или ΣB < 0                              KILL_NEGATIVE_COST
|ошибка| Q6, H4 или C6 > 5%                   KILL_HELDOUT
```

Иначе агрегатная модель — PASS, и читается равномерность. Суммы C6 и F6
для неё бесполезны: при аддитивных эффектах ключей они совпадают
тождественно. Поэтому — остатки шести групп после вычета общей
структурной части A + ΣB, по средним трёх повторов:

```
любой остаток <= 0                            UNRESOLVED
контроль, factorial F6: max/min > 1.05        UNRESOLVED_NOISE
зонд, cells C6: max/min <= 1.05               HORIZON_MAXIMISE_EFFECT_NOT_DETECTED_DAYS_UNMEASURED
                         1.05–1.10            UNRESOLVED
                         > 1.10               KILL_UNIFORM_WITHIN_BLOCK
```

Итог: PASS — только при агрегатной PASS и «не обнаружено». UNRESOLVED
любого вида — STOP. Days не измерена ни одним зондом.

### Отклонения от формулировки рецензии, до замера

- **Метки F6/C6 в правиле равномерности.** В рецензии контроль шума назван
  C6, а зонд — F6, с обоснованием «F6 изолирует (horizon, maximise), C6
  факториально балансирует». В коде и в прошлом дизайне наоборот: F6 —
  factorial, C6 — cells. Реализовано по смыслу рецензии: контроль —
  factorial (F6), зонд — cells (C6).
- **Подбор просмотра.** Чистое удвоение попадает в окно, только если
  отношение его границ не меньше 2, например 45–90 с. При 90 с весь gate
  стоит около 28.5 неделёных, то есть ~43 минуты — больше бюджета 35.
  Поэтому: удвоение до 4 с, пересчёт на 60 с, заморозка, а попадание в
  окно 45–75 с проверяется средним трёх свежих P1 шага 0.

### Обоснование дизайна: расчёт мощности. НЕ evidence.

`af2a.power_rationale()`: seed 20260927, 20 000 симуляций на строку. Шум —
мультипликативный N(0, σ) на каждый прогон, независимо. σ = 2.4% оценена
ПОСТФАКТУМ из A-F1: средний модуль разности двух повторов суммы 2.72% по
девяти разбиениям, σ = 2.72% / 1.128. Истина — доли неделёного из Gate A
и A-F1: A = 4.6%, каждая B_δ = 1.9%. Альтернатива — скрытый уровень
(группа, δ, days) с E = B/3, выбрана для иллюстрации.

```
σ      истина          INCONCLUSIVE   KILL | прошёл шум
                       по шуму        этот дизайн   ΣB из Q6, F6 отложен
2.4%   трёхуровневая      93.4%          4.3%           64.5%
2.4%   скрытый E=B/3      93.6%         68.5%           98.5%
1.2%   трёхуровневая       7.8%          0.0%           30.5%
1.2%   скрытый E=B/3       7.9%         77.7%          100.0%
0.6%   трёхуровневая       0.0%          0.0%            3.2%
0.6%   скрытый E=B/3       0.0%         92.6%          100.0%
```

Честное ожидание: при шуме A-F1 (2.4%) gate почти наверняка остановится
на шуме. Он имеет смысл, если на неделёном ~60 с шум не выше ~1.2% —
это и проверяет шаг 0 за ~3 минуты. Сила зонда равномерности не
просчитана: она зависит от НЕЗАВИСИМОГО шума групп, а в A-F1 группы по
~4.5 с внутри одного повтора расходились на 6–7%.

Что даёт PASS: право на A-F2b (отдельные B_δ). Не даёт: подключить
модель, выставить `UNDIVIDED_SHARE`, посчитать 64000, проектировать
Gate B. При FAIL или INCONCLUSIVE — STOP, и следующим falsifier'ом
становится instrumentation (отдельное решение).

### Разбор — постфактум, НЕ вердикт

- **Скрытый уровень (группа, δ, days).** По модели ошибка Q6 равна
  12E / Q6. Наблюдённые −0.17% соответствуют E ≈ −0.01 с, то есть нулю;
  иллюстративная альтернатива E = B/3 дала бы ошибку Q6 около 6.3%.
- **Доли.** A = 4.65% неделёного, средняя B_δ = 2.06%. Разложение Gate A на
  4000 (ноль степеней свободы) давало 3.65% и 1.97%. Это не проверка
  переноса: просмотры и машины разные, и перенос здесь не заявляется.
- **Порядок клеток C6:** (300, F), (300, T), (3600, F), (3600, T),
  (86400, F), (86400, T). Средние остатки по горизонту 7.63 / 7.78 / 7.93 —
  то же направление, что у Gate A на 4000 (горизонт 300 дешевле). Это
  ниже порога шума контроля и выводом не является.

### Что дальше — решения за рецензией

- **A-F2b (отдельные B_δ).** Опирается на агрегатную модель, а она PASS.
  Но по предрегистрации итог — STOP; разрешает ли агрегатный PASS сам по
  себе A-F2b — отдельное решение.
- **Равномерность** требует другого инструмента: шум контроля должен
  лечь заметно ниже 1.05. Это больше повторов и длиннее группы только
  для F6 и C6 — с расчётом мощности до замера — или поключевой
  instrumentation, который остаётся NO-GO.

`UNDIVIDED_SHARE = None`. Gate B и 64000 — NO-GO.
