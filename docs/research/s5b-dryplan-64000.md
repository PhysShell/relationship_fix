# Сухой план полного 64000 при balanced-g12: STOP

Локально, без Actions и без нового замера. Код — `execution/s5b_execution/
dryplan.py`, результат — `s5b-dryplan-64000.json`. `UNDIVIDED_SHARE`
остаётся `None`, `keycost` не подключён, balanced-g12 — кандидат политики
только для 64000.

## Вход

- **Реестр после 16000** — `checkpoint.json` из артефакта
  `s5b-reduced-16000` прогона `35904117457` (id 10802135037); sha256 архива
  `5e6456af…` совпал с digest GitHub и с записью в
  `s5b-stage2-look16000.md`; `Ledger.from_checkpoint` сверяет отпечаток
  сам: `ledger_digest 7ef59277bf6acc6b`, закрыто 17 286 концов из 33 696.
- **Вес юнита** — огибающая из рецензии, без модели деления:
  `W(rate) = 8835.4 с x seconds_for(rate, 64000) / seconds_for(120, 64000)`.
  Якорь — худший юнит пилота `36332456884` (рука со ставкой 120, блок
  δ = 60); δ = 60 взят худшим случаем для всех групп.
- **Семантика** — как у `scheduler.units_for`: юнит нужен, если открыт
  хоть один из его концов (`ledger.unit_is_needed`); раскладка —
  `layout.balanced_slices(12)`; упаковка — `S.assign` (LPT); makespan —
  `scheduler.makespan` при `MAX_PARALLEL = 6`.

## Вердикт: STOP

Первое жёсткое условие: 495 заданий при бюджете 2.5 ч против потолка
матрицы 256. Стресс x1.96 проходит (4.894 ч < 5.833 ч), план сохраняет
раскладку, identities и семантику реестра — но STOP от них не зависит.

## Факты для решения — без спасительных моделей

- **Реестр не выбросил ни одного юнита.** Полностью закрывшихся рук после
  16000 нет, а сбалансированная группа закрыта, только если закрыты все
  её 18 концов. Пар (рука, ключ), закрытых по всем трём долям, — 108 из
  11 232 (1.0%): выбрасывание закрытых ключей картины не меняет.
- **Огибающая завышает дешёвые блоки сознательно.** Насколько — не
  измерено и здесь не оценивается. Арифметика: чтобы 256 заданий по 2.5 ч
  вообще могли вместить ступень, суммарный ЦП должен быть не больше 640 ч,
  то есть 52% от 1225.7 ч по огибающей. Условие необходимое, но не
  достаточное.
- **Makespan — вопрос бюджета проекта, а не платформы:** 8.6 суток при
  шести слотах по огибающей, 16.8 при стрессе.

Ничего не запущено и не закреплено: явная политика balanced-g12 в
планировщик не вносилась. Дальнейшее — отдельным решением.
