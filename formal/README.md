# formal/ — semantic kernel, не весь pipeline

Здесь живёт МАЛЕНЬКАЯ формальная модель наблюдения: огрубление часов,
допустимые линеаризации, возможности, идентифицированное множество `N`.

Чего здесь НЕТ и не будет: CSV, pandas, адаптеров, 520 диад, дедупликации,
калибровки. Доказательство стоимостью в месяц, охраняющее `read_csv()`,
охраняет не то.

```
lake build          # собрать
./scripts/audit.sh  # собрать + запретить sorry/axiom + напечатать доверенную базу
```

Lean 4.34.0, **без Mathlib**: нужен только `List.Perm` из core. Ядро обязано
собираться из одного тулчейна, чтобы слово «доказано» не опиралось на
несколько гигабайт чужого кода и на доступ к сети.

Статус КАЖДОГО утверждения проекта — `docs/formal-model.md`. Без него фраза
«BOUNDED formally verified» была бы рекламой: доказано ядро порядка, а не
весь движок.
